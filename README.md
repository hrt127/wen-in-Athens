# wen in Athens we orgy smort

An interactive client-only app to learn Greeks (Delta, Gamma, Vega, Theta) with live BTC context.

## Features
- Sliders for option inputs
- Chart.js interactive chart
- Quiz mode with badges
- BTC play area with parsed market signals
- Strategy evaluation + exposure table

## Run
Open `index.html` in your browser or run:
```bash
python3 -m http.server 8080
